# GoodSocials

AI social media manager for LinkedIn. Writes high quality content, you approve
it in a kanban board, it schedules so you post regularly, close to daily.

- `CLAUDE.md` for anyone, human or agent, picking this repo up cold. It carries
  the verified LinkedIn constraints, which is the expensive knowledge here.
- `DECISIONS.md` for what is settled and why. Contradicting an entry needs a
  conversation, not a pull request.
- `ROADMAP.md` for what is next, ordered by risk.
- `DESIGN.md` for the accent, the board dimensions, and the one memorable thing
  on the landing page.

```
npm install
cp .env.example .env.local
npm run dev
```
